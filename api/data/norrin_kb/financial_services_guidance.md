# Norrin Internal Guidance: Financial Services AI Systems

## Source
Based on EU AI Act Annex III official guidance and Insurance sector AI Act analysis.

## Key Classification Signals for Financial Services

### Strong HIGH_RISK indicators
- System calculates creditworthiness scores for personal loan applications.
- System automatically calculates insurance premiums based on real-time data.
- Automated, consequential financial decisions.

### Potential MINIMAL_RISK / LIMITED_RISK indicators
- System is used internally for purely administrative tasks.
- Chatbots that answer customer FAQs but do not make decisions about individuals.

## Norrin Recommendation
Default to HIGH_RISK for systems dealing with creditworthiness or setting prices based on user data.
